# JD.S E-Portfolio

Standalone animated e-portfolio for Joseph Samadi.

## Files
- `index.html` main e-portfolio
- `assets/styles.css` visual styling, responsive layout, animations
- `assets/script.js` mobile nav, scroll reveal, tilt cards, cursor glow, demos
- `projects/` clickable project detail pages

## Deploy to Vercel
Import this folder/repository as a static site. No build command is needed.

## Local preview
Open `index.html` directly or run:

```bash
python -m http.server 3000
```

Then visit `http://localhost:3000`.
