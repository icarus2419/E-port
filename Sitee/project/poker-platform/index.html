Modular Multiplayer Poker Platform

A playable poker platform that separates the table engine, variants, human/AI players, lobby, serverless room state, and variance-reduction demos.

Play actual platform← Back to projects

What it shows

  • No-Limit Texas Hold’em plus a toy High Card variant.
  • Human and AI player types with legal action generation.
  • Room/lobby flow with browser UI, viewer-specific state, and Vercel API routes.
  • Seeded comparison demo using common random numbers and seat averaging.

Tech focus

  • Python backend structure and clean game-engine boundaries.
  • FastAPI-style API thinking plus a Vercel-compatible polling adapter.
  • Redis-ready data flow for rooms, players, and game state.
  • Browser interface designed around readable, real-time state updates.
