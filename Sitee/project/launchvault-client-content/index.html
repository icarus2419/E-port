LaunchVault Client Content Collection

A polished SaaS-style portal concept for collecting client website content, file uploads, revisions, reminders, and final launch approval in one calm workflow.

Problem

What it solves

Freelance web projects often stall because client content is scattered across email threads, texts, screenshots, and drive links. LaunchVault presents a clear workflow for gathering everything before a site launch.

Main features

Feature set

  • Client-facing collection portal for logos, copy, images, revisions, and sign-off.
  • Progress dashboard for missing items, pending revisions, overdue work, and launch readiness.
  • Pricing/landing sections and client portal previews built as reusable React components.
  • Motion-led product storytelling without requiring a backend for the portfolio demo.

Build

What I built

  • Converted the Vite build into a static portfolio demo with working relative asset paths.
  • Added custom project card art and a dedicated case-study page.
  • Connected the Demo flow to a form-card/upload animation matching the collection workflow.

Tech used

Stack

React, TypeScript, Vite, Tailwind, Framer Motion.
