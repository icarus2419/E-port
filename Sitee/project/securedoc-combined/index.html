SecureDoc Document Approval

A secure document approval workflow with role-based access, document uploads, reviewer decisions, version history, SHA-256 fingerprints, approval receipts, and audit-trail concepts.

JavaScriptNode.jsExpressMulterCSS
Open demo

Problem

What it solves

Approval workflows need a clear record of who submitted a file, who reviewed it, what changed, and which exact document version was approved. SecureDoc focuses on auditable document decisions instead of informal email approvals.

Main features

Feature set

  • Role-based app experience for submitters, reviewers, and admins.
  • Document uploads, reviewer decisions, change requests, version history, and approval receipts.
  • SHA-256 fingerprints stored with each document version.
  • Tamper-evident audit trail concepts for logins, uploads, comments, reviews, and downloads.

Build

What I built

  • Built a focused approval workspace for demo users with distinct permissions.
  • Included Express backend source for authentication, uploads, document decisions, and audit logging.
  • Adapted the portfolio demo so the approval app runs from static hosting with a browser-local API shim.

Tech used

Stack

JavaScript, Node.js, Express, Multer, HTML, and CSS.
